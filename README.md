# PETS - דף הורדה והתקנה

דף ההוראות להתקנת אפליקציית PETS (אנדרואיד), למשפחה וחברים.

- **הדף:** `index.html`. נפתח ב-GitHub Pages.
- **צילומי המסך:** בתיקייה `img/`. כולם ערוכים, בלי פרטים אישיים.
- **ה-APK:** לא נמצא כאן. הוא מועלה ל-**Releases** בשם `PETS.apk`. כפתור ההורדה מצביע תמיד על הגרסה האחרונה.

## עדכון גרסה
1. Releases → Create a new release → גוררים את ה-APK החדש בשם `PETS.apk` → Publish.
2. ב-`index.html` מעדכנים את מספר הגרסה בשני מקומות (ליד כפתור ההורדה ובתחתית הדף), את התאריך בתחתית, ואת הגודל.
